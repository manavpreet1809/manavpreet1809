## Projects

**[WellQuery](https://github.com/manavpreet1809/WellQuery)**
Answers general questions about diabetes and kidney health using 15 articles from the NIDDK. Every answer shows the passage it came from. Python, FastAPI, SQLite.

**[Sleep Tracker](https://github.com/manavpreet1809/Sleep-Tracker)**
A web app for logging sleep and seeing which habits line up with better nights. It can also import Garmin sleep data. Java, Spring Boot, PostgreSQL, React. Started as a group project with Dylan Crombie and Gary Liao.

**[TalentScope](https://github.com/manavpreet1809/TalentScope-Job-Market-Analytics-Platform)**
Collects job postings and shows hiring activity, top employers, salaries and the most mentioned skills. Python, PostgreSQL, Streamlit.

**[Online Multiplayer Game](https://github.com/manavpreet1809/seng300-202601-pg-3-Online-Multiplayer-Game-)**
A group project for SENG 300. Players sign in, join a lobby and play live matches. React, FastAPI, MongoDB.
